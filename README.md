# 🎯 쿠팡 블루오션 자동 발굴 시스템

카테고리만 입력하면 블루오션 키워드를 자동으로 찾아주는 데이터 기반 분석 도구

## ✨ 특징

- **⚡ 빠른 분석**: 15분 만에 블루오션 10개 발굴
- **🤖 완전 자동화**: 키워드 몰라도 됨 (자동 생성)
- **📊 데이터 기반**: 네이버 검색량 + 쿠팡 상품 수 분석
- **📁 엑셀 리포트**: 결과를 엑셀로 자동 생성
- **🎓 초보 친화적**: 비개발자도 쉽게 사용 가능

## 🚀 설치

### 1. 저장소 클론

```bash
git clone <repository-url>
cd coupang-blue-ocean-finder
```

### 2. 파이썬 가상환경 생성 (권장)

```bash
python3 -m venv venv
source venv/bin/activate  # Windows: venv\Scripts\activate
```

### 3. 라이브러리 설치

```bash
pip install -r requirements.txt
```

### 4. 환경변수 설정 (선택사항)

네이버 데이터랩 API를 사용하려면:

```bash
cp .env.template .env
# .env 파일을 열어서 API 키 입력
```

**네이버 API 키 발급:**
1. [네이버 개발자 센터](https://developers.naver.com/) 접속
2. 애플리케이션 등록
3. 데이터랩 (쇼핑인사이트) API 선택
4. Client ID와 Secret 발급
5. `.env` 파일에 입력

**참고:** API 키가 없어도 대안 방법(검색 결과 수 기반 추정)으로 동작합니다.

## 📊 블루오션 기준

시스템은 다음 기준으로 블루오션을 판정합니다:

| 항목 | 기준 | 의미 |
|------|------|------|
| **검색량** | 5,000 ~ 20,000회/월 | 적당한 수요 존재 |
| **상품 수** | 5 ~ 15개 | 경쟁 적음 |

### 기회 점수 계산 공식

```
기회 점수 = 검색량 점수 (50점) + 경쟁 점수 (50점)

검색량 점수 = (검색량 / 20,000) × 50
경쟁 점수 = ((15 - 상품수) / 15) × 50
```

**예시:**
- 검색량 10,000, 상품 8개
- 검색량 점수 = (10,000/20,000) × 50 = 25점
- 경쟁 점수 = ((15-8)/15) × 50 = 23.3점
- **총점 = 48.3점**

### 상태 라벨

| 라벨 | 의미 |
|------|------|
| ✅ 블루오션 | 조건 충족 (진입 추천) |
| ❌ 경쟁과다 | 상품 15개 초과 |
| ⚠️ 수요부족 | 검색량 5,000 미만 |
| ⚠️ 레드오션 | 검색량 20,000 초과 |
| △ 틈새시장 | 상품 5개 미만 |
| △ 검토필요 | 기타 |

## ⚙️ 설정

`config.py` 파일에서 블루오션 기준을 조정할 수 있습니다:

```python
# 블루오션 기준
MIN_SEARCH_VOLUME = 5000    # 최소 검색량
MAX_SEARCH_VOLUME = 20000   # 최대 검색량
MIN_PRODUCT_COUNT = 5       # 최소 상품 수
MAX_PRODUCT_COUNT = 15      # 최대 상품 수

# 크롤링 설정
CRAWL_DELAY = 2             # 요청 간 대기 (초)
MAX_RETRIES = 3             # 최대 재시도 횟수

# 키워드 생성 설정
TARGET_KEYWORD_COUNT = 150  # 목표 키워드 수
TOP_N_RESULTS = 10          # TOP N 출력
```

## 🔧 문제 해결

### "API 인증 실패"

**원인:** 네이버 API 키가 잘못되었거나 입력되지 않음

**해결:**
1. `.env` 파일 확인
2. API 키가 올바른지 확인
3. API 키 없이도 동작하지만 정확도는 낮아짐

### "쿠팡 차단됨"

**원인:** 쿠팡 서버에서 크롤링 차단

**해결방법:**
1. **1시간 후 재시도**
2. **VPN 사용**
3. **크롤링 딜레이 증가**
   ```python
   # config.py
   CRAWL_DELAY = 5  # 2 → 5초로 증가
   ```

### "키워드가 너무 적게 생성됨"

**원인:** 카테고리가 너무 좁거나 특수함

**해결:**
1. 더 넓은 카테고리 시도 (예: "주방칼" → "주방")
2. 목표 키워드 수 조정
   ```python
   # config.py
   TARGET_KEYWORD_COUNT = 200  # 150 → 200으로 증가
   ```

### "블루오션을 찾지 못함"

**원인:** 해당 카테고리에 블루오션이 없거나 기준이 너무 엄격함

**해결:**
1. 다른 카테고리 시도
2. 블루오션 기준 완화
   ```python
   # config.py
   MAX_SEARCH_VOLUME = 30000   # 20000 → 30000
   MAX_PRODUCT_COUNT = 20      # 15 → 20
   ```

### "실행 시간이 너무 오래 걸림"

**원인:** 키워드 수가 너무 많거나 네트워크가 느림

**해결:**
1. 목표 키워드 수 감소
   ```python
   # config.py
   TARGET_KEYWORD_COUNT = 100  # 150 → 100
   ```
2. 빠른 네트워크 환경에서 실행
