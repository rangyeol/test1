# 🎯 쿠팡 블루오션 자동 발굴 시스템

카테고리만 입력하면 블루오션 키워드를 자동으로 찾아주는 데이터 기반 분석 도구

## ✨ 특징

- **⚡ 빠른 분석**: 15분 만에 블루오션 10개 발굴
- **🤖 완전 자동화**: 키워드 몰라도 됨 (자동 생성)
- **📊 데이터 기반**: 네이버 검색량 + 쿠팡 상품 수 분석
- **📁 엑셀 리포트**: 결과를 엑셀로 자동 생성
- **🎓 초보 친화적**: 비개발자도 쉽게 사용 가능
- **🆕 고급 스크래핑**: Selenium 기반 봇 감지 우회 시스템

## 🆕 쿠팡 고급 스크래핑 시스템 (NEW!)

Selenium 기반의 고급 쿠팡 스크래핑 시스템이 추가되었습니다!

### 🚀 주요 기능

- **🤖 봇 감지 완전 우회**: undetected-chromedriver로 Akamai Bot Manager 우회
- **📊 상세 정보 수집**: 11개 컬럼의 완벽한 상품 정보 (상품명, 가격, 할인율, 판매구분, 별점 등)
- **🎨 GUI 인터페이스**: ttkthemes 기반의 사용하기 쉬운 GUI
- **⚡ 병렬 처리**: 여러 검색어 동시 처리 지원 (1-5개)
- **📡 네트워크 모니터링**: API 엔드포인트 자동 발견 및 분석
- **💾 자동 저장**: 중단 시 자동 저장 및 이어하기 모드
- **🖼️ 이미지 다운로드**: 상품 이미지 자동 다운로드 (선택사항)
- **🔄 중지 기능**: 안전한 중단 및 데이터 보존

### 📱 GUI 사용법

1. **GUI 실행**
   ```bash
   python coupang_gui.py
   ```

2. **검색어 추가**
   - 검색어 또는 URL 입력
   - '추가' 버튼 클릭 (여러 개 추가 가능)

3. **옵션 설정**

   - 이미지 다운로드: 상품 이미지 저장 (용량 주의)
   - 이어하기 모드: 중단 시 자동 재개
   - 네트워크 모니터링: API 엔드포인트 분석

4. **수집 시작**

### 💻 스크립트 사용법

```python
from coupang_scraper_integrated import initialize_driver, setup_coupang_main, run_full_pipeline

# 드라이버 초기화
driver = initialize_driver(headless=False)
driver = setup_coupang_main(driver)

# 방법 1: 검색어로 수집
result = run_full_pipeline(driver, '무선마우스', max_pages=5)

# 방법 2: 검색 페이지 URL로 수집 (필터, 정렬 등 유지)
result = run_full_pipeline(driver, 'https://www.coupang.com/np/search?q=무선마우스')

# 방법 3: 상품 상세 URL로 수집
result = run_full_pipeline(driver, 'https://www.coupang.com/vp/products/123456')

# 드라이버 종료
from coupang_scraper_integrated import close_browser
close_browser(driver)
```

## 📊 블루오션 기준

시스템은 다음 기준으로 블루오션을 판정합니다:

| 항목 | 기준 | 의미 |
|------|------|------|
| **검색량** | 5,000 ~ 20,000회/월 | 적당한 수요 존재 |
| **상품 수** | 5 ~ 15개 | 경쟁 적음 |

### 기회 점수 계산 공식

```
기회 점수 = 검색량 점수 (50점) + 경쟁 점수 (50점)

검색량 점수 = (검색량 / 20,000) × 50
경쟁 점수 = ((15 - 상품수) / 15) × 50
```

**예시:**
- 검색량 10,000, 상품 8개
- 검색량 점수 = (10,000/20,000) × 50 = 25점
- 경쟁 점수 = ((15-8)/15) × 50 = 23.3점
- **총점 = 48.3점**

### 상태 라벨

| 라벨 | 의미 |
|------|------|
| ✅ 블루오션 | 조건 충족 (진입 추천) |
| ❌ 경쟁과다 | 상품 15개 초과 |
| ⚠️ 수요부족 | 검색량 5,000 미만 |
| ⚠️ 레드오션 | 검색량 20,000 초과 |

## 🔧 문제 해결

### "API 인증 실패"

**원인:** 네이버 API 키가 잘못되었거나 입력되지 않음

**해결:**
1. `.env` 파일 확인
2. API 키가 올바른지 확인
3. API 키 없이도 동작하지만 정확도는 낮아짐

### "쿠팡 차단됨"

**원인:** 쿠팡 서버에서 크롤링 차단

**해결방법:**
1. **1시간 후 재시도**
2. **VPN 사용**
3. **크롤링 딜레이 증가**
   ```python
   # config.py
   CRAWL_DELAY = 5  # 2 → 5초로 증가
   ```

### "키워드가 너무 적게 생성됨"

**원인:** 카테고리가 너무 좁거나 특수함

**해결:**
1. 더 넓은 카테고리 시도 (예: "주방칼" → "주방")
2. 목표 키워드 수 조정
   ```python
   # config.py
   TARGET_KEYWORD_COUNT = 200  # 150 → 200으로 증가
   ```

### "블루오션을 찾지 못함"

**원인:** 해당 카테고리에 블루오션이 없거나 기준이 너무 엄격함

**해결:**
1. 다른 카테고리 시도
2. 블루오션 기준 완화
   ```python
   # config.py
   MAX_SEARCH_VOLUME = 30000   # 20000 → 30000
   MAX_PRODUCT_COUNT = 20      # 15 → 20
   ```

### "실행 시간이 너무 오래 걸림"

**원인:** 키워드 수가 너무 많거나 네트워크가 느림

**해결:**
1. 목표 키워드 수 감소
   ```python
   # config.py
   TARGET_KEYWORD_COUNT = 100  # 150 → 100
   ```
2. 빠른 네트워크 환경에서 실행
